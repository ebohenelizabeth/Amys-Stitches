# Amy's Stitches Website

A responsive website built for my sister's tailoring business, as part of my full-stack web development training at Tech Studio Academy.

**Live site:** https://ebohenelizabeth.github.io/Amys-Stitches/

## Built with
- HTML5
- CSS3 (Grid, responsive layout, Google Fonts)
- JavaScript (DOM, events, form validation)

## What I did
- Planned the layout and sections
- Wrote the HTML and CSS
- Prepared and optimized the photos
- Published the site with GitHub Pages
- Built an order form with JavaScript that validates input and sends a pre-filled WhatsApp message
