# Amy's Stitches Website

A responsive website I built for my sister's tailoring business in Lagos, Nigeria, after completing my full-stack web development training at Tech Studio Academy.

**Live site:** https://ebohenelizabeth.github.io/Amys-Stitches/

## Features
- Responsive layout that works on phones and desktops
- Services section and photo gallery of the business's real work
- Order form that checks required fields and sends a pre-filled WhatsApp message to the business
- Opening hours and WhatsApp contact button

## Built with
- HTML5
- CSS3 (Grid, responsive layout, Google Fonts)
- JavaScript (DOM, events, form validation)
- Git and GitHub Pages

## What I did
- Planned the layout and sections
- Wrote the HTML, CSS, and JavaScript
- Prepared and optimized the photos, and wrote alt text for each
- Built the order form and fixed a mobile bug where the form didn't reset after sending
- Published the site with GitHub Pages

## Notes
This is a personal project built for a family business. Photos are of the business's real work, used with permission.

## Run locally
Download the files and open `index.html` in your browser.
